## Smoke A (CRITICAL) — multi-tactic whole-proof verification works TODAY
`TrustedMathlibVerifier` builds `example <stmt> := by` then splits the proof string by newlines into
an indented tactic body (`mathlib_verifier.py:154-156`). So a whole proof passed as a newline-joined
string verifies. Tested 5 valid multi-tactic proofs + 1 deliberately-bad:
| proof | result |
|-------|--------|
| `exact h` (single) | ✓ |
| `exact ⟨h, h⟩` (anon constructor) | ✓ |

| `constructor <;> assumption` (`<;>`) | ✓ |
| `intro h`⏎`exact h` on a non-arrow goal | ✗ (correctly rejected) |
**5/5 valid pass, bad fails → SMOKE A PASS.** No `run_tac` needed; whole-proof H6 thesis is testable.

## Gold-compile-rate (real-Mathlib reconstruction viability)
LeanDojo states → `example` binders via `state_to_example` (`v40_wholeproof.py`): exactly-one-goal
states, hyps→`(...)`, instances (`inst✝`)→`[...]`, daggers stripped. Whole proof = newline-join of
traced tactics (linear only). On the LeanDojo **test** split: 652/2000 convertible+in-length;
**gold-compile-rate 13.7% (89/652)** — by proof length: 1-tac 64, 2-3 tac 24, 4+ tac 1. The rate is
limited by **version skew** (benchmark Mathlib v4.19 vs verifier scratch v4.30 — lemma renames) and
conversion imperfections. **Implication:** the verified tiers skew short; but H6/H7/H8/H9 are judged on
**dev exact-seq (text, no compilation)**, so the low rate does not block them — only the verified
headline (tiers) + H10 need compilable golds, and 89 suffice for two ~45-theorem tiers.
