### Key files per version (representative)

- **Shared core** (not version-scoped): `src/mini_elf_lean/mathlib_batched_verifier.py`
  (TrustedMathlibVerifier / GoldMathlibVerifier / NaiveBatchMathlibVerifier),
  `mathlib_verifier.py`, `v31_identifier_normalization.py` (canonicalization,
  hardened decode), `evaluate_v31_normalized_specialists.py`
  (`build_pool_for` / `score_cell`, reused by v32/v33).
- **Routers**: `src/mini_elf_lean/v{26..33}_mathlib_router.py` — the
  engineering switch (core→v24 untouched, mathlib→best specialist).
- **Per version**: `scripts/build_v{N}_*`, `train_v{N}_*`, `evaluate_v{N}_*`,
  `analyze/audit_v{N}_*`; `docs/V{N}_*.md`; `tests/test_v{N}_*.py`;
  `data/baselines/v{N}_*` (eval) + `data/processed/v{N}_*` (corpora).

## Protected / never-overwrite models (confirmed present)

- `data/models/token_seq2seq_v24_broad_residual` — **protected broad-core**; never
  retrained or overwritten across v25–v33. Routing sends all core theorems here,
  which is *why* routed broad-core is bit-for-bit identical every version.
- `data/models/token_seq2seq_v33_general_residual` — final recommended specialist.

## Flags

- **Large artifacts (>5 MB, 12 entries)** — mostly **legacy** model dirs:
  `proof_block_seq2seq_combined_v10_per_op` (14M), `token_seq2seq_v16` (9.9M),
  `token_seq2seq_v14` (9.7M), `v22_general_balanced_large` (4.4M), etc. Full list
  in `inventory.json → flags.large_artifacts_gt_5MB`. None are required by the
  v33 final system; see the Part 8 commit plan for exclude/keep decisions.
- **Stray logs (29)** — `*_stdout.log` / `*train*.log` under `data/`. Regenerable
  build/training stdout; candidates for exclusion (Part 8).
- **Duplicate report families** — each version ships a near-uniform doc set
  (DATASET / SPECIALIST_EVAL / ROUTED_SYSTEM / FAILURE_EXAMPLES / REPO_STATUS /
  …). These are intentional per-version snapshots, **not** accidental dups; the
  v34 final report (Part 4) is the single consolidated entry point.
- **Legacy bucket (194 MB, pre-v24)** — v0–v23 broad-core experiments
  (planner-blind, proof-block seq2seq, reranker sweeps). Historical; not part of
  the v33 system. Largest single contributor to repo data size.
- **External Mathlib scratch** — `~/code/mini_elf_mathlib_probe` (7.0 GB) is
  **outside** the repo tree (`inside_repo=False`), so it is structurally
  impossible to track. Mathlib v4.30.0 lives there; keep it separate (see
  `[[v25-mathlib-scratch-project-and-tradeoff]]`).

## What is obsolete vs essential

- **Essential to reproduce v33**: `token_seq2seq_v24_broad_residual`,
  `token_seq2seq_v33_general_residual`, the v31 canonicalization module + hardened
  decode, the trusted verifier, the v33 router, the v25–v33 seeds/manual rows,
  and the v33 baselines.
- **Historical (keep for provenance, not on the hot path)**: v0–v23 models +
  baselines, the per-version intermediate specialist variants (holdout/heavy/
  balanced ablations), and `*_stdout.log` build logs.
